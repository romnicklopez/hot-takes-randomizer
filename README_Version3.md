# Hot Take Randomizer

A tiny static web app that randomizes a list of "hot take" questions.

How to use:
1. Edit `hot-takes.txt` (one question per line).
2. Open `index.html` in your browser or host on GitHub Pages.
3. Click "Randomize" to get a random selection.

Features
- Lightweight static HTML/CSS/JS — no build step.
- Loads hot takes from a simple text file (hot-takes.txt).
- Option to pick multiple random items or shuffle the entire list.
